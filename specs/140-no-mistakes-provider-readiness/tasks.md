# Tasks: No-Mistakes Provider Readiness

**Input**: `specs/140-no-mistakes-provider-readiness/`
**Prerequisites**: `plan.md`, `spec.md`, `research.md`, `data-model.md`, `quickstart.md`, `checklists/task-clarity.md`

**Hard gate**: Implementation tasks below must not start unless their evidence task is complete and the local change is tied to a checklist item. The plugin must not encode provider-specific payment/transport policy in commands, skills, or companion runtimes, and must not strip provider capabilities to make policy easier. Provider adapters may expose only capability facts, such as available subscription transports, API/OpenRouter routes, auth probes, source limits, and launch mechanics. Every provider must pass through the same shared route policy: prefer subscription-backed transport when available; use API/OpenRouter only when subscription is unavailable, nonexistent, usage-limited, or explicitly selected; keep DeepSeek/GLM usable because their route reaches the same API fallback state rather than a separate policy class; reject ambiguous operator-facing `--auth-mode auto`; and disclose/source-audit the selected transport, auth path, billing path, and fallback reason. Approval policy must key off route/source risk, not provider name: any source-bearing API/OpenRouter route for any provider requires explicit approval with the same tuple and billing disclosure, and subscription-backed source-bearing routes get the same source-send/audit semantics across providers. Adding a new model must require a thin adapter/capability row, not a new policy branch. API/OpenRouter approval must expose two provider-neutral scopes: `session`, which can propagate through the current session only while provider, mode, source packet, prompt hash, scope resolution, request settings, auth path, billing path, selected route, and fallback reason are unchanged; and `once`, which authorizes only one matching source send and cannot be replayed. Any change in the tuple, approval scope, or consumed one-time approval state requires fresh approval before source is sent.
